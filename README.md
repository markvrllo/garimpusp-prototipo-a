# GarimpUSP · Protótipo A

Protótipo de interação do **GarimpUSP**, plataforma de compra e venda entre estudantes da USP com validação de matrícula, desenvolvido para a disciplina PRG0005 · Fundamentos em Empreendedorismo (2026), Entrega 5. Autoria do protótipo: Bianca Dip Façanário.

**Acesse:** https://markvrllo.github.io/garimpusp-prototipo-a/

## O que esta versão mostra

Use o seletor de telas no topo da página para navegar:

1. **Cadastro**: perfil do estudante com nº USP, e-mail @usp.br, instituto e campus.
2. **Validação**: envio do atestado de matrícula para liberar o acesso.
3. **Vitrine**: produtos e serviços de estudantes, com busca e etiquetas.
4. **Cadastro de produto**: nome, valor, descrição, foto, etiquetas e ponto de encontro no campus.

## Observações

- Protótipo de fidelidade média: não há banco de dados, login real nem pagamento. Os dados ficam só no navegador de quem acessa.
- Anúncios e números USP são de exemplo.
- O protótipo não foi testado com usuários.
